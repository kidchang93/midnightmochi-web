# SUBAGENTS — midnightmochi-web

파일이 `index.html` 한 장이라 대부분의 작업은 **서브에이전트 없이 직접** 하는 게 빠르고 안전하다.

## 역할 분담

| 역할 | 쓰는 경우 | 이 레포에서 |
|------|-----------|-------------|
| 탐색 (Explore) | 여러 파일·레포를 훑어야 할 때 | 거의 불필요. 예외: 상위 폴더 여러 프로젝트의 git log·docs 에서 포트폴리오·연혁 근거를 모을 때 |
| 구현 (general-purpose) | 독립된 산출물을 만들 때 | 이미지 자산(og.png·스크린샷·SVG) 제작처럼 `index.html` 과 겹치지 않는 일 |
| 리뷰 | 내 판단에 묶이지 않은 시선이 필요할 때 | 큰 개편(섹션 추가·구조 변경) 때만. `docs/REVIEW.md` 체크리스트 기준 |

## 병렬화

| 병렬 OK | 순차로 |
|---------|--------|
| 프로젝트별 이정표 근거 조사 (레포마다 하나씩) | `index.html` 편집 — 파일이 하나라 동시에 고치면 충돌한다 |
| 서로 다른 이미지 자산 제작 | 커밋·push (= 배포) |

## 서브에이전트 프롬프트에 반드시 넣을 것

- 이 레포의 `CLAUDE.md` 와 작업 관련 문서 경로: `docs/ARCHITECTURE.md`, `docs/DESIGN.md`, `docs/CODE_STYLE.md`, `docs/REVIEW.md`
- **공개 저장소**라는 사실과 공개 금지 항목(상세 주소·휴대폰·계약 문서·서명)
- 커밋·push 하지 말 것 (push = 배포)

## 결과물 검수

- `docs/CODE_STYLE.md` 의 토큰·클래스 규칙, `docs/REVIEW.md` 체크리스트를 통과한 것만 반영한다.
- 포트폴리오·연혁 문구는 근거(회사소개서·git log)를 서브에이전트가 함께 내놓아야 한다.
