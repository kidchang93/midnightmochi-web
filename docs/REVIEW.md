## 머지(push) 전 필수

```bash
python3 -m http.server 8000   # http://localhost:8000 에서 확인
```

- [ ] 데스크톱 폭과 900px 이하·560px 이하에서 레이아웃이 깨지지 않는다
- [ ] 브라우저 콘솔에 에러가 없다
- [ ] 바꾼 이미지·SVG 가 실제로 뜬다 (파비콘은 탭에서 확인 — 캐시 때문에 강력 새로고침 필요할 수 있음)
- [ ] push = 배포다. 사용자가 요청했을 때만 커밋·push 한다. 계정은 `kidchang93` (`git config user.email` 이 개인 메일인지 확인)

## 체크리스트

| 구분 | 확인 |
|------|------|
| 범위 | **변경된 모든 줄이 요청으로 추적 가능한가 (요청과 무관한 리팩터링·포맷·주석 변경 없음)** |
| 사실 | 포트폴리오·연혁 문구에 근거(회사소개서·git log)가 있는가 |
| 공개 | 상세 주소·휴대폰·계약 문서·서명이 들어가지 않았는가 |
| 스타일 | 색은 `:root` 토큰만, 클래스 변형 패턴(`.work.feature` 식)을 따랐는가 |
| 접근성 | 장식 이미지 `alt=""`, 의미 있는 이미지에 한국어 alt, 포커스 링 유지, reduced-motion 에서 움직임 꺼짐 |
| 성능 | 새 스크린샷을 가로 560px JPG 로 줄였는가 |
| 링크 | 외부 링크 `target="_blank" rel="noopener"`, 앵커(`#works` 등)가 실제 id 와 맞는가 |
| 문서 | 파일·구조가 바뀌면 `CLAUDE.md` 파일 표와 `docs/` 를 같이 고쳤는가 |

## 흔한 실수

- 새 섹션을 추가하고 헤더 `.nav` 링크나 `scroll-padding-top`(고정 헤더 68px) 을 안 맞춤
- `og.png` 를 바꾸고 공유 미리보기 캐시 때문에 반영 안 된 줄 앎 (카카오·슬랙 등은 캐시가 길다)
- `.reveal` 을 JS 없이도 숨기게 만들어 JS 꺼진 환경에서 내용이 사라짐
